# 原型：论文检索 + 评审流水线状态模型

## 要回答的问题

这个原型模拟**论文检索服务**的完整生命周期——从 PDF 入库、建索引、到文档级检索——
以及它如何支撑上层评审流水线（`历史文章` / `待评议` / `评审步骤` 三个文件夹模型）。

需要验证的点：

1. **入索引 → 检索的闭环**：分块策略、加权 Mean Pooling、BM25 聚合、RRF 融合、精排——每一步状态变化是否正确
2. **文件名元数据提取**：中文文件名各种格式的解析是否鲁棒
3. **增量索引**：新增论文后 BM25 全量重建的代价是否可感知
4. **评审池概念**：历史文章和待评议如何映射到检索接口
5. **状态一致性**：模拟崩溃（中途退出）后索引是否可恢复

## 如何运行

```bash
python -m prototype.tui
```

## 模型/向量模拟

原型**不使用真实模型**——所有 embedding 和 reranker 分数用确定性模拟函数替代。
这让我们聚焦于管道逻辑本身，而不是模型加载的工程细节。
