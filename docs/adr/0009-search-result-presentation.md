# 检索结果呈现：综合相似分主线 + 原始分审计 + 完整命中原文

**Context**: 检索结果需供评审 Agent 判断"检索到的 Reference 是否真的与 Subject 相似"。四个原始分（BM25 / 向量余弦 / RRF / 精排）值域各异（无界负值、[-1,1]、[0,~0.033]、[0,1]），裸数字会让 LLM 误读，无法达成"防止低相似被误判"的目的。

**Decision**: 给评审 Agent 的每篇 Reference 呈现三段：① 归一化「综合相似分」（0~1，有精排用精排分、无精排用 RRF 归一化）作为主线；② 四个原始分 + 排名作为客观审计数据；③ 命中 Chunk 的**完整**原文（不截断）。原始分不丢弃、不伪造。

**Why**: 综合分让 LLM 一眼判断相似度高低，原始分 + 原文让 LLM 能深究"为什么相似/不相似"，二者结合防止低相似检索结果被当成强相似依据。

## Considered Options

- **只给四个原始分**: 值域混杂，LLM 无法判断高低，违背防误判目的。放弃。
- **只给综合分、不给原始分**: 丢失客观审计数据，LLM 无法核实。放弃。
- **命中原文截断 200 字**: 用户明确要求给出完整相似原文，截断会丢失判断相似性的关键内容。放弃。
